PENTING UNTUK CODEX

Ini adalah template project lengkap Promptly. File index.html di root adalah kode landing page HTML asli pengguna dan reference/original-landing-page.html adalah salinan referensinya.

Pilih folder yang berisi package.json sebagai Project Root. Dialog pemilih folder mungkin hanya menampilkan folder, tetapi pilih root yang sama tempat package.json berada.

Instruksi utama untuk Codex:
1. Baca index.html dan reference/original-landing-page.html sebelum mengubah UI.
2. Pertahankan desain asli: biru #168bf2, kuning #ffd13d, font Space Grotesk dan DM Sans.
3. Gunakan struktur Next.js yang sudah ada (app/, lib/, public/, supabase/) untuk website; index.html root adalah referensi kode asli, bukan pengganti app/page.tsx.
4. Audit seluruh project, jalankan lint/typecheck/build, perbaiki dan tes ulang.
5. Jangan mengklaim tes/deployment berhasil jika belum benar-benar dijalankan.
6. Jangan push GitHub atau deploy tanpa izin eksplisit pengguna dan target yang jelas.

Baca CODEX_TASK.md untuk persyaratan fitur, keamanan, Supabase, Stripe, dan deployment.
